# 축구선수 키우기 ⚽

고등학교 1학년부터 프로 입단, 연봉 협상, 3부→2부→1부→월드 리그 이적, 개인상과 발롱도르, 은퇴와 다음 세대까지 —
같은 세계의 다른 플레이어들과 경쟁하는 방치형 축구선수 커리어 게임. 구조는 「기사 키우기」(방치형 하단바 + 캠프 창 + 서버 랭킹)를 따랐다.

## 실행

```
npm start                 # 서버 + 웹 게임 (http://localhost:3140)
npm install && npm run app        # 데스크탑 하단바 앱 (기본 서버에 접속)
npm run app:local         # 데스크탑 앱을 로컬 서버(3140)에 접속
```

- 웹 게임은 서버 주소를 이렇게 정한다: `?server=주소` → `window.SOCCER_SERVER` → (localhost·onrender.com에서 열렸으면) 같은 주소 → `src/net.js`의 `DEFAULT_SERVER`.
- 서버는 Node 기본 모듈(http, node:sqlite)만 쓴다. Node 22.13 이상. 데이터는 `DATA_DIR`(기본 `./data`)의 `soccer-star.db`.

## 게임 흐름

```
[출전] 스태미나가 남는 동안 리그 경기를 연달아 뛴다 (경기 90초 + 이동 8초, 꺼 둔 시간도 진행)
   ↓  하단 띠에서 경기 재생 — 골·도움·태클·선방·스킬 연출
[귀가] 스태미나 부족 / 부상 / 귀가 명령 / 시즌 종료 → 집에서 휴식
   ↓
[정비] 훈련(돈) · 스킬(SP·연습 노트) · 장비 강화 · 시설 · 연애
   ↓
[시즌 결산] 순위·개인상 → 고교는 진급, 고3은 드래프트, 프로는 이적시장(재계약·이적·방출), 34세부터 은퇴
```

- **경기 재생**: `match.js`의 `matchPlan`이 90분을 그대로 늘어놓지 않고 볼 만한 장면(내 활약·골·슛·선방)에 실제 시간을 몰아준다. 장면은 패스 전개 → 슛 → 결과 → (골이면) 세리머니 순서이고, 내 장면에서는 카메라가 확대되고 느려진다. HUD 시계·점수도 같은 시간표(`matchClock`, `scoreAt`)를 쓴다.

- **고교**: 3시즌(9경기씩). 고교 중에는 스카우트 평가(등급·예상 순위)가 보인다.
- **드래프트**: 고3이 끝나면 동기 80명 중 고교 3년 성적(OVR·평점·골/도움/클린시트·수상·팔로워, 포지션 보정)으로 순위. 1라운드 1~10순위 1부 · 11~20 2부 · 21~30 3부(각 리그 약팀부터), 2라운드 31~40 3부. 순위가 높을수록 계약금·연봉이 크다. 41위부터 미지명 → 무소속.
- **프로 리그**: 3부 · 2부 · 1부 · 월드. 시즌마다 18경기.
- **이적시장**: 시즌이 끝날 때마다 열린다. 계약이 끝났으면 재계약(성적·팀 수준에 따라 안 올 수도 있음)과 다른 팀 제의 중에서 고르고, 아무 제의도 없으면 방출. 계약 중이면 더 강한 팀의 영입 제의만 오고 거절할 수 있다. 23세 미만은 잠재력 가산점.
- **무소속**: 리그 경기 없이 훈련·시설·스킬만. 입단 테스트(스태미나 30, 3부는 유망주에게 문이 넓다)에 붙으면 1년 계약, 15분마다 이적시장이 다시 열린다.
- **연봉 협상**: 제의마다 한 번 +15%(잘 받아 줌) / +30%(반반) 요구. 거절되면 원래 조건만 남는다.
- **스타일**: Lv 15에 포지션별 3종 중 선택, Lv 50에 칭호.
- **스킬**: 바나나킥·무회전킥·칩슛·바이시클킥·마르세유 턴·스루패스·슬라이딩 태클·PK 선방 등 19종. 레벨업 SP로 배우고 연습 노트로 숙련(최대 10).
- **부상**: 경기당 약 2%(스태미나가 낮으면 2배, 32세부터 1.4배), 재활센터로 확률·기간 감소.
- **인기**: 팔로워 단계(무명→레전드), 단계마다 스폰서 자동 계약(경기당 수입 + 장비).
- **연애**: 인기에 따라 만날 수 있는 상대가 늘어난다. 호감이 오르면 썸→연애→약혼→결혼, 휴식 속도 보너스. 6시간 넘게 연락이 없으면 호감 감소, 0이 되면 이별.
- **은퇴**: 34세부터 선택, 40세 강제. 업적만큼 능력치 보너스를 받은 다음 세대로 같은 계정에서 다시 시작.

## 여러 명과 경쟁 (서버)

- **계정**: 닉네임 = 계정. 복구 코드로 다른 기기에서 이어서.
- **같은 세계**: 리그와 팀이 모두에게 같다. 최근 7일 안에 접속한 다른 플레이어가 상대 팀에 있으면 그 선수 이름으로 골이 나오고, 순위표에 🌍 표시가 붙는다.
- **랭킹**: 몸값 · OVR · 팔로워 · 통산 골 · 승부차기 점수.
- **승부차기 도전**: 두 선수의 슈팅·선방 능력으로 서버가 계산(5번씩, 동점이면 서든데스), Elo 점수. 5초에 한 번.
- **발롱도르**: 3일마다(한국 시간 2026-10-01 0시 기준) 서버 전체에서 그 기간의 골·도움·MOM·클린시트·평점 × 리그 가중치로 순위. 끝난 기간은 다음 요청 때 확정되고, 1~10위는 다음 접속 때 상금·팔로워·수상 기록을 받는다. 승부차기 점수도 같은 주기로 초기화.

## 배포 (Render)

1. 이 폴더를 GitHub 저장소로 올린다.
2. Render에서 Web Service 생성 — Build `npm install --omit=dev`, Start `npm start`, 환경 변수 `NODE_VERSION=24`.
3. 받은 주소를 `src/net.js`의 `DEFAULT_SERVER`에 넣는다.
4. ⚠️ Render 무료 플랜은 디스크가 재시작·재배포 때 지워진다. 계정·세이브를 유지하려면 유료 Persistent Disk를 붙이고 `DATA_DIR`를 그 경로로 지정해야 한다.
